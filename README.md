# Лабораторна робота 3: Тестування SPI Master (Testbench)
**Виконав:** Стернюк Назарій, група КІ-406  

## Опис проєкту
Цей проєкт містить VHDL-реалізацію інтерфейсу SPI (Master) та відповідний тестбенч для симуляції його роботи. 
Тестбенч перевіряє коректність ініціалізації транзакції, передачі даних (MOSI) та їх прийому (MISO) в режимі loopback.

## Структура файлів
* `spi_master.vhd` — Головний модуль (Top-level).
* `spi_tx.vhd` — Модуль передавача (Shift register, видача на MOSI).
* `spi_rx.vhd` — Модуль приймача (Shift register, зчитування з MISO).
* `spi_master_tb.vhd` — Тестбенч, що генерує тестовий байт `0xAC` та керуючі сигнали.
* `run.ps1` — PowerShell скрипт для автоматичної компіляції та запуску симуляції (GHDL).
* `doc/` — Директорія зі збереженими еталонними осцилограмами етапів симуляції.

1. Переконайтеся, що в системі встановлено компілятор **GHDL**.
2. Відкрийте термінал PowerShell у папці проєкту та виконайте скрипт:
   ```bash
   ./run.ps1
3. Відкрийте згенерований файл wave.vcd на сайті VCDrom або у десктопній програмі GTKWave для аналізу часових діаграм.
